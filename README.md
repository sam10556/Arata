# Usarata

A responsive landing page built with React, TypeScript, and Vite for a school project.

## Live Demo

🌐 [View the live website](https://usarata.vercel.app/)

## Built With

- React
- TypeScript
- Vite
- CSS
- ESLint

## Features

- Responsive landing page
- Modern and clean UI
- Reusable React components
- Responsive design for desktop and mobile
- Fast development and production builds with Vite

## Project Purpose

This project was built as a landing page for a friend's school project, with a focus on creating a clean, responsive, and easy-to-navigate user experience.
